# Focus Pilates
App web (PWA) del estudio. React + esbuild, datos en Supabase.
- `npm install && npm run build` genera `dist/` (estático, se puede subir a GitHub Pages, Netlify, Cloudflare Pages).
- Con GitHub: Settings → Pages → Source: GitHub Actions. Cada push a `main` publica.
- Sin GitHub: arrastrar la carpeta `dist` a https://app.netlify.com/drop
